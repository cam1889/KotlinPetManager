Descripción breve de la aplicación.
KotlinPet Manager es una aplicación Android desarrollada en Kotlin y Jetpack Compose bajo la arquitectura MVVM y Material 3,
diseñada para optimizar la gestión de pacientes en clínicas veterinarias. La app permite registrar pacientes con un ID 
automático mediante un formulario dinámico con menús desplegables y un switch para urgencias. Además, calcula y muestra 
tiempos de espera personalizados según el tipo de consulta (de 10 a 45 minutos para atenciones normales y 15 segundos para
urgencias) integrando un temporizador en tiempo real con alertas visuales que indican cuándo el paciente está listo para ingresar.
